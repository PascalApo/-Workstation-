# SSP Workstation

Persönliche Organisations- und Planungs-App für deinen Consultant-Alltag bei SSP.

## Starten

```bash
cd C:\Users\pasca\Documents\ssp-alltag
npm run dev
```

Browser: **http://localhost:5173**

## Wichtigste Tools

### Kommandozentrale (Start)
- Tagesüberblick, Top-3, Statistiken, Morgen-Routine
- Schnellzugriff auf alle Planungs-Tools

### Planungs-Hub
- **Kanban** – Eingang → Geplant → In Arbeit → Erledigt (Drag & Drop)
- **Eisenhower-Matrix** – Dringend/Wichtig priorisieren
- **Wochenplan** – 3 Wochenziele + Aufgaben pro Tag
- **Eingang verarbeiten** – Quick Captures einordnen

### Flow-Kalender
- Termine & Aufgaben per Drag & Drop verschieben
- Magnetisches 15-Minuten-Raster

### Fokus-Modus
- Eine Aufgabe, null Ablenkung – ideal zwischen Meetings

### Projekte
- Aufgaben & Meetings nach Kunde/Projekt gruppiert

### Quick Capture (+ Button / Strg+K)
- Gedanken sofort erfassen, später im Eingang verarbeiten

### Command Palette (Strg+K)
- Schnellnavigation zu allen Bereichen

## Tastenkürzel

| Kürzel | Aktion |
|--------|--------|
| `Strg+K` | Command Palette |
| `+` (unten rechts) | Quick Capture |

## Daten

Alles lokal im Browser (IndexedDB). Backup unter **System → Backup**.
