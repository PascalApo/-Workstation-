# SSP Workstation – Quick-Add (Chrome-Erweiterung)

Aufgaben und Termine von jeder Webseite direkt in die SSP Workstation schicken.

## Installation (einmalig, ~1 Minute)

1. Chrome öffnen → Adresse `chrome://extensions` eingeben
2. Oben rechts **„Entwicklermodus"** aktivieren
3. **„Entpackte Erweiterung laden"** klicken
4. Diesen Ordner auswählen: `chrome-extension`
5. Fertig – das SSP-Icon erscheint in der Symbolleiste (ggf. über das Puzzle-Symbol anpinnen)

## Nutzung

- **Symbolleiste:** Icon klicken → Titel eingeben → speichern.
  Ohne Datum landet der Eintrag im **Eingang (Inbox)** zur späteren Planung.
- **Rechtsklick auf markierten Text:** „Auswahl als Aufgabe in SSP Workstation"
- **Rechtsklick auf Seite:** „Seite als Aufgabe in SSP Workstation"
  (Seitentitel wird Titel, URL wird als Notiz angehängt)

## Einstellungen

Im Popup unter **Einstellungen** die App-Adresse anpassen,
falls die Workstation nicht unter `http://localhost:5175` läuft.
